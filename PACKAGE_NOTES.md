# Airport Navigator current package

This package is based on the user-provided `airport-navigator-main.zip` level set and adds the attached MEM and BNA hero images as optimized WebP files.

Added image files:
- `public/airport-visuals/mem.webp`
- `public/airport-visuals/bna.webp`

The package preserves the current app state from the supplied ZIP, including MEM/BNA airport selection, route logic, feedback form update, tester popup, and removed redundant timing breakdown UI.

For manual GitHub update: unzip this package and upload/replace the repository files with the contents of the `airport-navigator-current` folder.
